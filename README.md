# editor-ruler

> 한국어 문서: [README.ko.md](README.ko.md)

A Word-like horizontal ruler for web rich-text editors — margins, first-line indent, drag handles. Editor-agnostic core with per-editor adapters (Froala first; Tiptap and CKEditor 5 planned).

Scaffold in progress — see the first PR for the initial packages.
