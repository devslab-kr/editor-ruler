웹 에디터에는 줄자가 없었습니다.
이제 어디에나 달 수 있습니다.

Froala·TinyMCE·CKEditor 5·Quill — 어떤 범용 WYSIWYG 에디터도 Word처럼 여백과 들여쓰기를 끌어서 조절하는 줄자를 제공하지 않습니다. editor-ruler는 에디터에 종속되지 않는 코어와 얇은 어댑터로 그 공백을 채우는 오픈소스입니다.

의존성 0 TypeScript cm · in · px 키보드 접근성 Froala 어댑터 Apache-2.0

바로 만져보기

문단을 클릭한 뒤 ▼(첫 줄 들여쓰기) · ▲(좌/우 여백) 핸들을 드래그하세요. 방향키도 됩니다.

Word처럼 끌어서 정렬하기

이 문단을 선택하고 위 삼각형 핸들을 움직여 보세요. 왼쪽 아래 삼각형은 왼쪽 여백, 위 삼각형은 첫 줄 들여쓰기, 오른쪽 아래 삼각형은 오른쪽 여백입니다.

문단마다 들여쓰기가 따로 유지됩니다. 위 삼각형을 아래 삼각형보다 왼쪽으로 끌면 내어쓰기(hanging indent)도 됩니다.

이 플레이그라운드는 순수 contenteditable 위에서 코어만으로 동작합니다 — Froala 어댑터도 같은 코어를 씁니다.

시작하기 — npm

npm install @devslab/editor-ruler
import { createRuler } from '@devslab/editor-ruler';

const ruler = createRuler(mountElement, {
  unit: 'cm', // 'cm' | 'in' | 'px'
  getMetrics: () => ({ contentWidth, leftMargin, rightMargin, firstLineIndent }), // px
  onChange(change, phase) {
    // px 값을 현재 문단(들)에 적용; 드래그를 놓는 순간 phase === 'commit'
  },
});

ruler.refresh();      // 선택/내용이 바뀔 때 호출
ruler.setUnit('in');  // 눈금 전환

시작하기 — CDN (빌드 도구 없이)

번들러 없이 <script> 한 줄로 씁니다. 전역 EditorRuler가 노출됩니다.

<script src="https://cdn.jsdelivr.net/npm/@devslab/editor-ruler@__PACKAGE_VERSION__/dist/index.global.js"></script>
<script>
  const ruler = EditorRuler.createRuler(document.getElementById('ruler-mount'), {
    unit: 'cm',
    getMetrics: () => ({ /* ... */ }),
    onChange(change) { /* ... */ },
  });
</script>

Froala 어댑터도 동일합니다: @devslab/editor-ruler-froala/dist/index.global.js를 로드하면 전역 EditorRulerFroala.defineRulerPlugin이 노출됩니다 (코어 포함 단일 파일).

버전 지정: @0.1.0(정확 고정) · @0.1(패치 자동 반영 — 권장) · @latest(항상 최신 — 메이저 포함이라 브레이킹 체인지 위험, jsDelivr가 별칭을 최대 12시간 캐시).

Froala에서 실제로

아래는 진짜 Froala 에디터에 어댑터를 붙인 모습입니다. 문단을 클릭하고 줄자 핸들을 드래그해 보세요 — 툴바의 줄자 버튼(toggleRuler)으로 줄자를 켜고 끌 수 있습니다.

이 문단을 선택하고 줄자 핸들을 드래그해 보세요.

문단마다 여백과 첫 줄 들여쓰기가 따로 유지되고, 드래그 한 번이 undo 한 단계로 기록됩니다 (Ctrl+Z로 확인).

에디터 안의 "Unlicensed" 표시는 Froala 트라이얼 빌드의 워터마크입니다 (Froala는 상용 에디터로 별도 라이선스가 필요합니다) — 이 플러그인과는 무관합니다.

Froala 연동

npm install @devslab/editor-ruler-froala froala-editor
import FroalaEditor from 'froala-editor';
import { defineRulerPlugin } from '@devslab/editor-ruler-froala';

defineRulerPlugin(FroalaEditor); // 인스턴스 생성 전에 1회

new FroalaEditor('#editor', {
  rulerEnabled: true, // 기본 true
  rulerUnit: 'cm',
  // 툴바에 줄자 토글 버튼을 넣으려면:
  toolbarButtons: ['bold', 'italic', '|', 'toggleRuler'],
});

defineRulerPlugin은 표준 Froala 플러그인(ruler)과 함께 줄자 아이콘이 달린 toggleRuler 툴바 커맨드를 등록합니다 — 버튼이 활성 상태(fr-active)로 현재 표시 여부를 보여줍니다. pluginsEnabled를 직접 지정한다면 'ruler'를 포함하세요. 드래그는 선택 문단의 margin-left/right·text-indent를 갱신하고 제스처당 undo 스텝을 1회 기록합니다.

API 요약

createRuler(mount, options)줄자를 마운트하고 Ruler 핸들을 반환
options.getMetrics(){ contentWidth, leftMargin, rightMargin, firstLineIndent } — 전부 px
options.onChange(change, phase)드래그 중 'drag', 놓는 순간 'commit' (undo 경계)
ruler.refresh()선택/내용 변경 시 메트릭 다시 읽기
ruler.setUnit(u)'cm' | 'in' | 'px' 눈금 전환
ruler.destroy()DOM과 리스너 정리

핸들은 ARIA 슬라이더입니다 — ←/→ 1px, Shift 10px, Home/End. 테마는 --edr-bg·--edr-fg·--edr-handle 등 CSS 변수로 바꿉니다.

자주 묻는 것

탭 스톱은요? HTML에는 탭 스톱 모델이 없어 의도적으로 범위 밖입니다. 여백·들여쓰기는 CSS와 1:1이라 어디서나 안전하게 동작합니다.

결과물 HTML은 어떻게 나오나요? 순수 인라인 CSS입니다 — <p style="margin-left: 75px; text-indent: 38px">. 어디로 내보내도(메일·다른 페이지·CMS) 레이아웃이 유지됩니다.

테이블은요? 셀 안의 문단은 정상 들여쓰기되고, 셀 자체에는 스타일을 쓰지 않습니다(CSS가 셀 margin을 무시). Word처럼 줄자에서 테이블 컬럼 폭을 끄는 마커는 로드맵에 있습니다.

다른 에디터는요? 코어가 에디터 불문이라 Tiptap·CKEditor 5 어댑터가 로드맵에 있습니다. 어댑터는 "선택 문단 읽기/스타일 쓰기/undo 연결"만 하면 됩니다 — Froala 어댑터가 예시입니다.
