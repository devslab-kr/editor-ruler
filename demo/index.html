A Word-like ruler for the web

Select this paragraph and drag the triangular handles above. The bottom-left triangle moves the left margin, the top triangle moves the first-line indent, and the bottom-right triangle moves the right margin.

Each paragraph keeps its own indentation, exactly like a word processor. Try a hanging indent: drag the top triangle to the left of the bottom one.

This demo runs on a plain contenteditable element — the same core drives the Froala adapter.
